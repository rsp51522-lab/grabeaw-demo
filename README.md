# Grabeaw 見積書PDF自動作成機能　導入手順書（README）

## 結論

既存のApps Scriptプロジェクト（Grabeaw 商品注文・帳票管理システム）に **新規ファイル1つを追加し、既存ファイル1つを置き換えるだけ** で、フォーム送信から「見積書PDF作成 → ドライブ保存 → URL書き込み → メール送信」までが全自動になります。既存機能（注文登録・顧客管理・手動PDF作成メニュー）は一切変更していません。

## 実現される流れ

```
Googleフォーム送信
  ↓ （既存）フォーム回答へ追加
  ↓ （既存）注文管理・注文明細・顧客管理へ登録、注文番号発行
  ↓ （新規）帳票入力シートへデータ反映
  ↓ （新規）御見積書シートへ自動転記
  ↓ （新規）御見積書シートのみPDF化（A4縦・余白小・グリッド線/シート名/ページ番号なし）
  ↓ （新規）設定シートの「見積書保存先フォルダID」のフォルダへ保存
  ↓ （新規）同名ファイルがあれば古い方をゴミ箱へ移動してから保存
  ↓ （新規）PDFのURLを フォーム回答・顧客管理・注文管理 へ書き込み
  ↓ （新規）顧客へPDF添付メール送信（テストモード付き）
  ↓ （新規）管理者へ「〇〇様の見積書を保存しました」通知
エラー時 → エラーログシートへ記録＋フォーム回答へ「PDF保存エラー」
```

保存ファイル名は、会社名がある場合「株式会社〇〇御中_御見積書_GR-20260714-001.pdf」、無い場合「浅野太郎様_御見積書_GR-20260714-001.pdf」です。ファイル名に使えない文字（\ / : * ? " < > |）は自動で除去されます。

## 導入手順（所要10分）

### 手順1. コードを貼り付ける

1. スプレッドシート「Grabeaw管理表」を開いていた既存のApps Scriptプロジェクト（ファイル一覧に `03_OrderService.gs` などがあるプロジェクト）を開く
2. 左のファイル一覧の「＋」→「スクリプト」で新規ファイルを作り、名前を `12_AutoEstimate` にする
3. `コード/12_AutoEstimate.gs` の中身を全部貼り付けて保存（Ctrl+S / Cmd+S）
4. 既存の `無題 2.gs` を開き、中身を全部消して `コード/無題2_置き換え.gs` の中身を貼り付けて保存
5. （推奨）既存の `10_Menu.gs` も同様に `コード/10_Menu_置き換え.gs` で置き換えて保存

### 手順2. 設定シートを確認する

| キー | 必須 | 説明 |
|---|---|---|
| 管理者メールアドレス | **必須（現在空欄）** | 通知・テストメールの宛先。**必ず入力してください** |
| 見積書保存先フォルダID | 設定済み | PDFの保存先。既に入っているのでそのままでOK |
| メール送信モード | 自動追加 | 初回実行時に「テスト」で自動追加される。顧客へ実際に送るときだけ「本番」に変更 |
| 顧客メール送信 | 自動追加 | 「ON」で自動追加される。顧客メール機能自体を止めたいときは「OFF」 |
| 顧客メール件名 | 自動追加 | **メールの件名をここで自由に修正できる**（コード変更不要） |
| 顧客メール本文 | 自動追加 | **メールの本文をここで自由に修正できる**。文中の {宛名} が「株式会社〇〇 御中」「〇〇様 様」に自動置換される。セル内改行は Option+Enter（Windows: Alt+Enter） |

### 見積書の内容を修正したいとき

見積書のレイアウト・文言は「御見積書」シートを直接編集すれば、次回のPDFから自動で反映されます（PDFはこのシートをそのまま出力しているため）。作成済みPDFを直したい場合は、帳票入力シートのB2セルで注文番号を選び、宛名・件名・明細を手で修正してから `testSaveEstimate` を実行すると、修正済みの内容でPDFが作り直されます（古い同名PDFは自動でゴミ箱へ）。

### 手順3. 初回認証

1. Apps Scriptエディタで関数選択プルダウンから `testSaveEstimate` を選ぶ
2. 「実行」をクリック → 「承認が必要です」と出る
3. 自分のGoogleアカウントを選択 → 「詳細」→「（プロジェクト名）に移動」→「許可」
4. もう一度「実行」をクリック

権限は既存の appsscript.json に定義済み（Drive・Sheets・Forms・メール送信）のため、追加のスコープ設定は不要です。

### 手順4. トリガー確認（インストール型）

既存の `onFormSubmit` インストール型トリガーをそのまま使うため、**新しいトリガーの追加は不要**です。確認方法は、エディタ左の時計アイコン（トリガー）を開き、「onFormSubmit ／ スプレッドシートから ／ フォーム送信時」が1件あることを確認するだけです。もし無ければ、スプレッドシートのメニュー「Grabeaw注文管理」→「フォームとトリガーを初期設定」を実行すると自動で作成されます。

## テスト方法

### テスト1. 手動実行（安全・顧客にメールは飛ばない）

1. エディタで `testSaveEstimate` を実行（またはシートのメニュー「見積書PDF自動作成テスト」）
2. 注文管理シートの最新注文（例: GR-20260714-001）でPDFが作られる
3. 確認ポイント（4つ）
   - ドライブの見積書フォルダにPDFが保存されている
   - 注文管理の「見積書PDF」列に「PDFを開く」リンクが入っている
   - フォーム回答・顧客管理の「見積書PDF」列にURLが入っている
   - 管理者宛に「〇〇様の見積書を保存しました」＋「【テスト送信】御見積書を送付いたします」の2通が届く

### テスト2. フォームからの通し試験

1. 実際のフォームから自分のメールアドレスでテスト注文を送信
2. 1〜2分以内に上記4点が自動で揃うことを確認

### 本番切り替え

設定シートの「メール送信モード」を「テスト」→「本番」に書き換えるだけです。以後、顧客のメールアドレス宛にPDF付きメールが直接送信されます。

## 想定エラー一覧

| エラー内容（エラーログの表示） | 原因 | 対処 |
|---|---|---|
| 注文番号 XXX が見つかりません | 注文管理に該当行が無い | フォーム送信からやり直す |
| 保存先フォルダを開けません | フォルダIDが間違い/削除済み | 設定シートのIDを確認、または「保存先フォルダを作成」を実行 |
| PDFエクスポートに失敗しました。HTTP 4xx | 認証切れ・権限不足 | testSaveEstimate を実行して再認証 |
| 顧客メールアドレスが不正のため送信できません | フォーム入力のメールが不正 | 顧客管理のメールを修正し testSaveEstimate で再実行 |
| 帳票セル設定が未完了です | 御見積書シートの構成変更 | シート構成を戻すか TEMPLATE_CELLS を修正 |
| 明細がありません | 注文明細に該当注文が無い | 注文明細シートを確認 |

エラー発生時は必ず「エラーログ」シートに日時・処理名・注文番号・エラー内容・スタックトレースが記録され、フォーム回答の該当行に「PDF保存エラー」が入ります。管理者メールアドレスが設定済みならエラー通知メールも届きます。

### PDF再作成のやり方（リカバリ）

帳票入力シートの注文番号セル（B2）に対象の注文番号を選び、`testSaveEstimate` を実行してください。同名の古いPDFはゴミ箱へ移動され、新しいPDFで置き換わります（ゴミ箱から30日間は復元可能）。

## よくある失敗例

1. **管理者メールアドレスが空欄のまま** → テストモードのメールが1通も届かず「動いていない」ように見える。まず設定シートに入力する。
2. **新しいトリガーを追加してしまう** → onFormSubmit が2重実行される。トリガーは既存の1件のみにする。
3. **御見積書シートのレイアウトを変更** → 転記セル位置（TEMPLATE_CELLS）とズレて帳票が崩れる。レイアウト変更時はコード.gs の TEMPLATE_CELLS も合わせて修正する。

## 次にやるべき1ステップ

**設定シートの「管理者メールアドレス」を入力**してから、`testSaveEstimate` を1回実行してください。
